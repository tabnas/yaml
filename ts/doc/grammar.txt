Tokens:
  CL  = colon : (separates a key from its value)
  DE  = document end marker ... (column 0)
  DR  = directive line, e.g. %YAML / %TAG (column 0)
  DS  = document start marker --- (column 0)
  EL  = block sequence item dash "- "
  IN  = line indentation (count of leading spaces)
  KEY = map key: bare text, number, string, or keyword
  QM  = explicit-key marker ? in flow {? k : v }
  VAL = value: bare text, number, string, or keyword

Ignored tokens:
  CM = comment
  LN = newline (line break)
  SP = whitespace (spaces or tabs)
